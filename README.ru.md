# SkyStudio 360°

**Процедурное небо 360° в браузере** — 12 видов облаков с физическим описанием, день / закат / ночь, солнечное и лунное затмения, самолёты с тремя режимами инверсионного следа, кисти для рисования облаков и экспорт бесшовных панорам 2:1 в PNG для скайбоксов и 3D-сцен.

[English version](README.md)

![Поле кучевых облаков, экспорт панорамы 360°](docs/panorama-cumulus.jpg)

*Обе картинки — необработанные панорамы 360°, сохранённые кнопкой 💾 PNG.*

## Как запустить

- **Онлайн:** `https://rostislav-kr.github.io/skystudio-360/` (после включения GitHub Pages для репозитория)
- **Без интернета:** скачайте [`dist/skystudio-360.html`](dist/skystudio-360.html) и откройте двойным щелчком — всё в одном файле.

Интерфейс на русском и английском (кнопка 🌐 или `?lang=ru` / `?lang=en` в адресе).

## Возможности

| | |
|---|---|
| **12 видов облаков** | Cirrus fibratus, uncinus, vertebratus; кучевые humilis и congestus; перисто-кучевые; высококучевые floccus / lacunosus / undulatus; двухъярусное небо; кучево-дождевые с ливнем и молниями; авиатрасса |
| **24 готовые темы** | Сцены «вид облаков + время суток + Солнце/Луна», девять из них настроены по фотографиям неба |
| **Свет** | HDR-сияние Солнца с короной Ми, сумеречные лучи, просвечивание Солнца сквозь тонкие облака, серебристая кайма |
| **Ночь** | Звёзды и Млечный Путь, Луна с фазами и венцом, «Кровавая Луна», полное солнечное затмение с короной и протуберанцами |
| **Самолёты** | Двухдвигательный лайнер, четырёхдвигательный «джамбо», сверхзвуковой с дельта-крылом; следы на 11,2 / 7,8 / 4,2 км ведут себя по-разному |
| **Панель физики** | LCL, EL, CAPE и сдвиг ветра для каждого вида, мини-профиль T(z); режимы эволюции (рождение и распад, атлас, суточный цикл, прохождение фронта) |
| **Редактор** | Кисти перистых, кучевых и «барашков» в трёх режимах (светлая, объёмная, с уплотнением), мягкий ластик, перемещение Солнца, Луны и ветра |
| **Экспорт** | Эквиректангулярная панорама 2560×1280 PNG — подходит как фон окружения в Blender, Unity, Godot, three.js |

## Как устроено

Все облака считаются в одном фрагментном шейдере GLSL из аналитического шума (FBM и гладкий «billow»-шум), без текстур — кроме процедурно генерируемой карты Луны.

Чтобы обзор шёл на 60 FPS, купол облаков 360° **запекается** один раз в текстуру 2048×1024 (плотность, наклон, детали, тень), а покадровый проход добавляет поверх только освещение, Солнце и Луну, звёзды, самолёты и дождь. Купол перезапекается, только когда меняется форма облаков. Запекание можно выключить (🔥) — тогда все октавы шума считаются в каждом кадре.

Структура кода — в [README.md](README.md#how-it-works).

## Разработка

Нужен Node.js 18+.

```bash
npm install
npm run dev      # локальный сервер http://localhost:5173
npm run build    # собирает dist/skystudio-360.html — один самодостаточный файл
```
